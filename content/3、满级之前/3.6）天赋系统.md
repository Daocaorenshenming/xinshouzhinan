### **天赋系统简介**

当你到达10级，你可以解锁天赋页面（快捷键N）并且开始获得天赋点数。

天赋是你职业内部的特色加点，需要选择某一专精作为你的分支发展方向，同时在高等级时再次选择英雄天赋分支。

从10级开始，每升1级都会得到一点天赋点，总共可以获得81点天赋点，其中

- 通用天赋树，34点
	
- 专精天赋树+专精最终天赋，34点
	
- 英雄天赋树，13点
	

所有天赋点数都是交替获得，即1级通用天赋、1级专精天赋。所以你在升级的过程中可以慢慢考虑和尝试每一个新天赋。

而哪怕是同一个专精、同一个英雄天赋，在不同场景下也会选择不同的天赋方案。

而理解天赋，即是魔兽世界职业最重要的一环。

- **专精**（10级解锁）

![image.png](https://flowus.cn/preview/9bc48d42-ec94-424c-b723-7cbdfc7b7aa4)

游戏内的每一个职业都有3个不同专精（德鲁伊比较特殊，有4个）

比如上图是牧师的3个专精，虽然他们都同属牧师这个职业，但是它们之间的**玩法逻辑**有相当大的区别。

尤其是你可以注意到上图中“暗影”专精牧师是伤害输出专精，而“戒律”和“神圣”是治疗者专精。

而其他职业一样，不同的专精可能会**承担不同的职责**。

同时，不同专精所需要的**主属性**可能不同，比如圣骑士的“惩戒”专精是力量主属性近战输出，“神圣”专精是智力主属性治疗。

所以，当你到达10级可以选择专精的时候，**建议可以把几个专精都尝试一下**，来初步确定自己的偏好。

而对于天赋系统而言，不同专精

- 有着大致相同的“职业通用天赋树”（仅有少量区别）
	
- 有着截然不同的“专精天赋树”、“专精最终天赋”
	
- 有着两两共用的“英雄天赋树”
	
	- “两两共用”指的是虽然每一个职业也有3套“英雄天赋”，每个专精只对应其中2套“英雄天赋”。只能在这两套中二选一，比如
		
	- 比如牧师有3个专精（戒律、神圣、暗影）和3套英雄天赋（执政官、神谕者、虚织者），它们的对应关系为
		
		- 戒律，可选（神谕者、虚织者）
			
		- 神牧，可选（执政官、神谕者）
			
		- 暗影，可选（执政官、虚织者）
			

总归，在不同专精、天赋树、英雄天赋的排列组合下，魔兽世界的职业变得丰富多变，充满了可玩性。

- 通用天赋、专精天赋（10级解锁）

**天赋树介绍**

![image.png](https://flowus.cn/preview/36e4b69e-21e5-492d-ab9b-d28af63af2c0)

职业通用天赋和专精天赋是你在升级过程中最先接触到的天赋，在10级的时候你会各获得1点天赋点，随后直到70级每次升级交替获得1点天赋

```
- 职业通用天赋树（上图左侧红色），是你职业公用的天赋树（部分职业、专精会有少量区别），它们大部分提供一些防御、增益、属性、机动等功能性天赋。

- 专精天赋树（上图右侧蓝色），是决定你职业真正运转机制的天赋，它们大部分是你伤害、爆发、治疗的核心。
```

建议新手升级阶段过程中仔细阅读你即将点出的天赋，如果有可能，最好实际点出试验一下，以方便加深你的职业理解。

```
- 左键点击天赋即可完成加点，而且可以右键取消重新加点。

- 在战斗中无法修改天赋

- 在大秘境开始后，在副本内无法修改天赋，需要退出本外。
```

**天赋的解锁和限制**

![image.png](https://flowus.cn/preview/3788acc9-fe2a-4662-a10c-9613477f6be3)

![image.png](https://flowus.cn/preview/ec5c6d11-f032-4327-b4b1-f8db43a3bf7c)

一般来说，天赋树下方的天赋会更为强大，尤其是最底层的天赋。为了防止玩家跳过初级天赋而堆叠底层天赋，暴雪设计了天赋的层级解锁。

所以你至少

```
- 在天赋的上半区投入8点天赋才能解锁中间区域

- 在天赋的上半区和中部区域总计投入15点才能解锁底部区域
```

同时，你的所有天赋必须按照图中天赋树的连线来依次解锁，即需要前置天赋。

所以，你永远无法同时点出那些最强大的天赋，必须要根据战斗所需有所取舍。

- 英雄天赋（71级解锁）

**英雄天赋介绍**

![image.png](https://flowus.cn/preview/f4bfe3f3-4795-418d-bb89-9df5a8cff182)

```
![image.png](https://flowus.cn/preview/844c21b0-7a9b-4b2b-98b6-611844cb3991)

当你到达71级，你可以获得并且选择英雄天赋。英雄天赋相当于你的职业第二次出现大分支。

英雄天赋和专精是两两共用的，

  - “两两共用”指的是虽然每一个职业也有3套“英雄天赋”，每个专精只对应其中2套“英雄天赋”。只能在这两套中二选一，比如- 比如牧师有3个专精（戒律、神圣、暗影）和3套英雄天赋（执政官、神谕者、虚织者），它们的对应关系为

  - 戒律，可选（神谕者、虚织者）

  - 神牧，可选（执政官、神谕者），如上图

  - 暗影，可选（执政官、虚织者）
你可以在当前专精的两个英雄天赋选择一个

  - 不同英雄天赋之间同样风格迥异。如果你是新手，那么**建议你都尝试一下**。

英雄天赋一共可以获得13个天赋点数，它们恰好可以把你的所选的英雄天赋点完。

  - 同一英雄天赋内部的区别很小，只有部分天赋需要二选一，比如上图神谕者英雄天赋内部只有两个“二选一”天赋。
```

**英雄天赋的切换和缩略**

![image.png](https://flowus.cn/preview/ccd2adc8-9e20-4702-bfe7-afb0ca52f940)

如果你想在切换英雄天赋，点击上方的红色区域图标即可。

而由于英雄天赋内差别很小，你也可以点击蓝色区域的缩略按钮，将那些固定的天赋隐藏起来，仅保留可抉择的天赋点。

- 最终天赋（81级解锁）

**最终天赋介绍**

![image.png](https://flowus.cn/preview/0621cd83-2124-44eb-bbbb-8f6d78de6276)

当你81级时，可以解锁最终天赋，它位于专精天赋的最下方。

最终天赋是12.0版本新增的天赋，一般是你专精最强大的特色机制，并且可以和你的其他技能产生重要关联。

最终天赋分为4点（1+2+1），其中第4点是最关键的，将在**满级时获得**。

**最终天赋的邪修**

一般来说，绝大部分的职业都必须将最终天赋点出，但是由于最终天赋其实和专精天赋共用天赋点。

极少数职业可能会选择不点最终天赋，而将天赋点留给上方的专精天赋，从而衍生出一些更为独特的打法。这一般被称为“邪修”

对于新手来说不推荐这么做。

- PVP天赋和战争模式（20级解锁）

**PVP天赋**

![image.png](https://flowus.cn/preview/4f3c1a58-8304-4e08-9e76-8529cdf40b96)

PVP天赋仅在战争模式（野外）、决斗和PVP场内生效（比如战场、竞技场等）

它们**不会**在地下城或者团队副本之类的PVE场景中有任何作用。

PVP天赋一共有3个栏位，它们分别在**20、40、60级解锁**。

- 天赋方案配置、分享、导入导出

**天赋方案的保存和分享**

![image.png](https://flowus.cn/preview/39343022-6f86-4a9d-a9e5-c742ccb2a7dd)

```
你可以在天赋页面的左下角新建和保存多套天赋配置，方便你随时切换

同时你也可以选择“分享”你的配置，可以选择导出为字符串或者直接将其作为链接贴在聊天框中。
```

**天赋字符串和导入**

当你选择导出天赋字符串“复制到剪贴板”，或者从其他地方复制一个字符串，你将会得到一串数字和英文组成的代码，比如下方就为我神牧配置的字符串

`Plain Text CEQAR03Gt7xPmcDNOjs2Zlb3yCDAAAAAAYBmZWGzMmZMMDzsMzYGAAAAzYWmBzMzwMmZAMTNAmZDDhxsMAjBWMzMLAaGMGDzMAzMzAD`

此时你可以选择“导入”将这行代码复制进去，就可以完整的将其复制成你的天赋了。

所以当你在网上看到一篇攻略，可以看看是否其有分享此类字符串，这样你就不用一个一个点天赋了。
