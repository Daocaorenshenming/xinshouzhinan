### 游戏中的社交分类

除了各类聊天频道之外，这种临时的社交场景之外。（参见）

你还可以建立长久而稳固的社交关系

- 添加好友
	
	- 添加角色好友
		
	- 添加战网好友
		
	- 添加战网（实名）好友
		
- 加入公会
	
- 加入社区
	
- 好友列表和添加好友

**好友列表**

![image.png](https://flowus.cn/preview/4163ab06-26b4-4a5e-a04f-a700bb44193b)

你可以在聊天框的左上角或者按O键打开你的好友列表，里面你可以查看好友的在线状态。

**好友的类型**

游戏中好友分为

- 游戏角色好友，仅在该角色在线的时候可以互动
	
- 战网好友，可以通过战网聊天系统查看对方其他角色、游戏活动，并且可以离线聊天
	
	- 同时，你可以在战网好友的基础之上，在好友列表点击对方ID，将其添加为“亲密好友”这样对方会置顶在你的好友列表最上方。
- 战网好友（实名），以你的真实身份添加好友
	
	- 请注意，不要随意在网上暴露你的真实信息！

**添加好友**

![image.png](https://flowus.cn/preview/d34fc33b-b7ff-4133-b761-9caa5ebda961)

![image.png](https://flowus.cn/preview/188b2df2-798b-4611-a409-1023e0a79144)

你可以通过如下方式添加游戏好友或者战网好友

```
- 点击好友列表左下方的“添加好友”按钮

- 可以右键点击目标头像，选择“添加好友”

- 在小队/团队聊天频道，或者公会成员列表中，右键对方ID，选择“添加好友”
```

**战网好友的隐私设置**

![image.png](https://flowus.cn/preview/72214098-578c-4cb6-880c-2a3cbf4cd718)

为了确保隐私，请确保你的“战网好友”设置符合你的期望。

你可以使用战网客户端打开或者直接网页访问战网设置，在“隐私”中调整选项。

其中比较重要的是

```
- 推荐好友的好友（防止其他人偷窥你的好友列表）

- 实名好友
```

请根据自己的偏好来进行设置。

- 公会

**公会是什么**

公会是魔兽世界中最常见也是最传统的组织体系。最大可以容纳1000人。

公会不仅仅是一个社交体系、组织体系，同样也是一种独特的游戏玩法。

你可以在里面找到队友、参加活动、获得各种奖励，而最重要的是，你可以在游戏中找到一个可以归属的地方。

现在的公会是可以跨服跨阵营组建的，所以你无需担心自己会被孤立在外。

**公会福利**

![image.png](https://flowus.cn/preview/2f44dac2-67a0-46e7-999b-b4d1624df5bd)

除了玩家之间互相带来的便利之外，公会还有一些系统自带的福利。

- 公会福利技能，比如坐骑加速、炉石CD从30分钟缩短到15分钟、可以随时随地的打开公会银行的宝箱、跑尸速度加快，公会成员之间的信件秒到
	
- 公会商人（联盟暴风城/部落奥格瑞玛）出售的各类小玩意，比如公会战袍（可以由会长自行设计的战袍）、可以传送主城的披风、各类坐骑和宠物等等
	
- 跨服务器、阵营聊天和组队，在公会中，所有成员可以自由沟通，而不需要受到
	
- 公会工匠，在满级后，你可能需要制造业专精玩家帮你做定西。而你的订单可以选择“公会订单”，从而实现跨服、跨阵营的工匠服务。（否则你只能在自己的服务器慢慢喊话找人）
	
- 公会银行，你可以在银行查看或使用公会银行（需要权限）
	
- 公会修理，如果公会允许并且资金充裕，你可以每天使用一定额度的公会资金作为你的修理费
	

**公会在玩家中的非官方分类**

一般来说，由于公会玩家的兴趣偏好和组织形式不同，玩家自己会将公会划分成几种粗略的类型：

```
- PFU公会，PFU=Play for uber，以追求史诗团队副本进度作为第一目标的公会，一般会招揽最为熟练稳定的玩家。

  - 名人堂公会，指已经获得游戏史诗团队副本顶尖排名的公会（现在版本指国服前50/200的公会，而以前则条件更为苛刻）

- PFF公会，PFF=Play for fun，侧重休闲的公会，但一般也会开设史诗团本和英雄难度团本。

  - 千钧公会，指获得史诗难度成就千钧一发的公会（版本结束前击杀所有史诗BOSS），一般有能力完成新版本的所有史诗击杀。属于中等进度的公会。

- 大秘境公会，指以大秘境为主，而较少或者轻度组织团队副本的公会。

- PVP公会，以PVP活动为主的公会，现阶段已经较少存在。

- 纯休闲公会，仅轻度或者小规模组织公会活动，平时以娱乐为主
```

除此之外，还有许多依据兴趣而构建的公会，比如某个动漫爱好者聚集地，RP（角色扮演）公会等。

如果你想找到一个明确群体的公会，那么在加入之前请注意一定要问清楚。

但是对于新人而言，随机的遇到朋友，相互感兴趣一起玩才是最重要的。

**查找和加入公会**

![image.png](https://flowus.cn/preview/08db621d-84a5-41bc-ac23-0163a3e7099b)

游戏中目前自带一个“公会查找器”，但是在大部分时间实际处于废弃状态。此处也仅作介绍，并**不推荐新人通过此功能寻找公会**。

```
- 除非你十分着急想要在练级途中享受一些公会福利
```

在你没有加入公会的情况下，你可以按J键盘，打开“寻找社区”页面，里面会出现一些正在招募会员的公会。

而除此之外

```
- 如果你是一个新手，建议可以在新手频道问问有没有面向新手的公会，一般里面会有非常多的人心同学来给你介绍。-

- 如果练级途中你碰到了不错的朋友，也可以试试加入他的公会

- 游戏外的社区也有许多公会招募的帖子和工具，如果你有兴趣，可以问问AI这些社区的地址。
```

但总而言之，公会和社交是一个非常个人化并且随缘的东西，我的个人建议是**不要强求**，找到合适的公会远比随机加入一个公会更为重要。

**公会会阶和权限**

![image.png](https://flowus.cn/preview/4ae12b64-3cf8-45a5-8523-af810bca967c)

每个公会可以自定义其独有的会阶，这些会阶可以单独设立权限（比如发言权限、公会银行权限、公会资金权限等）

但大体上分为

```
- 会长，拥有所有的公会权限

- 公会官员，拥有较多公会权限，并且拥有独立的公会官员频道（不常用）

- 会员
```

在大部分公会中，这些权限的差异并不明显，你也无需为了所谓的会阶而担心，大部分情况下他们只是一个名称区别而已。

**公会信息和成员列表**

![image.png](https://flowus.cn/preview/7b41b7c1-f0f2-46b2-b6d7-85fa17a704be)

![image.png](https://flowus.cn/preview/c1b2467e-3442-41bd-8f24-a4fde2c5f0fb)

加入公会后，你将会自动加入公会频道，如果你的会阶可以发言（大部分情况下都可以），那么你就可以尝试和其他公会成员交换信息和聊天了。

同样，你也可以使用公会页面的成员列表查看一些公会信息，比如他们的在线情况、公会成员的装备获取情况，公会最近完成的成就等。

**退出公会**

如果你想退出当前公会，那么在聊天框中输入 /退出公会 或者 在公会名单里点击自己名字选择“退出公会”即可。

**建立公会**

如果你想自己建立一个公会，需要到阵营主城（联盟暴风城、部落奥格瑞玛）找到公会NPC（可以问卫兵具体位置）

然后领一张申请表，并且集齐4名其他玩家的签名，你就可以成立公会了。

```
- 别忘了给你的新公会设计徽章和公会战袍！
```

- 社区

![image.png](https://flowus.cn/preview/bcb83d94-1098-4a51-b2a0-6e4fc79bfbaf)

游戏内的是一种更松散的组织，你可以认为它就是一个聊天群

- 你可以打开公会和社区界面（按J键），以“战网账号”的身份创建或者加入社区。
	
- 如果你有权限，可以点击社区右下方的“邀请成员”发送邀请链接到聊天框，其他人点击后即可加入
	
- 你可以在聊天框内点击邀请链接，或者直接复制黏贴其他人的社区链接/代码，直接加入社区
	

一般来说，只有较少的社区会定期组织活动，在大部分情况下大家还是更倾向于找到一个公会。

- 请注意，这里的“社区”指的是游戏内的正经社区，它的功能就是一个聊天群。
	
- 某些游戏外的奇怪组织也会打着”社区团”的名义让你交付费MVP之类的，而最后大部分卷款跑路。
	
	- 所以新手玩家千万要警惕打着“社区团”名义的付费工作室。不要被骗！
