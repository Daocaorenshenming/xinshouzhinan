# 角色的整体概念
魔兽世界角色由服务器、阵营、种族、职业、专精构成，除此之外你还可以选择性别和自定义外观。  
**其中最重要的是职业**。其他东西都可以在以后随时更改（当然，很多是付费服务），  
- **服务器**，游戏的主要游戏内容都可以跨服完成，但是部分内容是需要同服乃至同阵营完成的。可后期付费更改。
- **阵营**，游戏分为部落和联盟两个主要阵营，在剧情上它们存在对立和合作并存，并且剧情存在差异，但对于满级之后的主要游戏体验影响很少，玩家可以跨阵营组队完成大部分游戏内容。但它影响一些旧版本的剧情，以及在某些功能上存在阵营隔离。可后期付费更改。
- **种族**，不同阵营包含若干可选种族，有不同特长和外观，以及所有种族都拥有一些独立的剧情体验。可后期付费更改。
	- 游戏默认每个阵营解锁各8个种族，以及拥有7个额外的“同盟种族”，需要在游戏内达成一定条件后解锁，下详。
- **职业**，不同种族可选的职业不一样，游戏当前区分为13个职业。某些职业只有特定种族可以选择。选择后**不可修改**
	- 比如唤魔师只能由龙希尔种族（龙人）选择
- **专精**，专精是进入游戏内随着升级解锁的职业分支，每个职业有3个不同专精，对应不同的天赋树（游戏技能加点）和玩法。可在游戏内随时切换它们。
- **角色外观和性别**，可以之后随时在游戏内的“理发店”进行调整（收取少量金币），所以你觉得好看就好看啦
此处仅提要，详细介绍请展开下文

# **选择服务器 ——推荐中等人口的优势服**
 
魔兽世界区分不同的“大区”和“服务器”，现在魔兽世界的**绝大部分内容都是跨服的**，比如组队、拍卖行。  
任意服务器都可以正常完成绝大部分的游戏内容。但是某些游戏内容（比如制造业订单、邮箱）是需要同服务器乃至于同阵营玩家才能完成的。   
所以对于新手而言，一般**推荐中型并且己方阵营有不错的人口基数**服务器，并且在不了解游戏的情况下，**尽量不要选择鬼服。**   
当然，如果你有朋友已经在玩魔兽世界了，那么听他的建议肯定更合理。  
>[!quote] **“阵营”**，即部落/联盟的概念在下一小节介绍

所以以下仅主观的列出一些推荐的服务器（当然，你也可以选择一个自己喜欢的服务器和名称，影响并不很大）

除此之外，还有一些服务器虽然人口基数和阵营条件都不错，但是由于一些历史原因就不做推荐了，具体的故事你们可以慢慢在游戏中了解。

### 选择和更换服务器
![[Pasted image 20260929172632.png]]
- 如果你不小心选择了服务器，又希望切换到其他服务器建立角色，那么在角色选择画面的最上方，你可以找到切换服务器的按钮，
- 你建立的所有角色（不同服务器）都会在右侧列出，你选择它们的时候也会进入到不同的对应服务器。
- 如果你已经建立了角色，但是希望迁移到其他服务器，那么就需要在游戏商城或者战网商城里购买角色转移服务，当然，是需要花钱的。

### **额外知识：一些服务器概念**
**服务器合并**  
除了通用的跨服系统之外，由于魔兽世界历史较长，部分的小服务器实际上已经真正意义上合并为一个大服务器，比如“霜之哀伤/回音山/神圣之歌/遗忘海岸”就实际上是一个服务器，只是在建立角色时的服务器后缀名称不同而已。
 
 **PVE/PVP服务器**  
曾经魔兽世界（包括现在的怀旧服），拥有PVE和PVP服务器的区别，用来区分玩家是否可以在野外自由对战。而现在由于可以在游戏内随时开关PVP选项，所以已经不做此类区分。
 
 **RP服务器**  
RP=Role Playing，即角色扮演服务器。RP是一种特殊的游戏玩法，里面是一些希望更带入游戏故事背景的玩家组成的，比如在游戏内的发言或者行为完全符合自己的角色身份（比如你的角色是一个人类圣骑士，那么在游戏中的发言和行为都需要显得更像一个圣骑士），并且遵循一些社区规范。换成更时髦的概念来理解，它更像是一种“剧本杀”（当然，RP传统远比剧本杀早、硬核、严谨）或者说游戏内的cosplay。当前国服RP服务器仅有 五区-**金色平原** 一个。如果你更偏好此类游戏风格，那么加入金色平原就对了。

**地域服务器**  
当前国服开放的地域服务器有两个，
- 晴日峰（江苏）
- 丽丽（四川）
如果喜欢和同乡一起玩游戏，或者希望更低的物理延迟，则可以在服务器选择页面的**“推荐服务器”**中找到。

# 选择阵营 ——喜欢>一切  
![[Pasted image 20260929172621.png]]
魔兽世界分为部落和联盟两个阵营，在游戏玩法上它们几乎没有区别。而**满级后的主要游戏绝大部分内容也是阵营互通的**。（比如联盟和部落完全可以组队一起去打副本）
不同的阵营有不同的**种族**和分支剧情（主线则基本一致），不用的种族可选的**职业**也不一样。 每个阵营和种族也有丰富的历史故事背景，在**主要游戏内容之外**依旧会深刻地影响一些你的游戏体验。  
>[!quote] **“职业”**的概念会在下一个小节介绍

### **对新手的阵营建议**  
如果你是第一次玩魔兽世界，永远的第一要务是满足自己的喜好——你喜欢什么就玩什么。 除此之外:
- 选择合适的种族会比选择阵营更重要
- 如果有朋友，可以尽量和他们一个阵营，对于某些场景会更便利些
- 新手尽量选择和服务器一致的优势阵营，也可以获得些许便利

### **阵营的共同点**  
- 游戏的主要内容都可以跨阵营完成的，**你可以和你对立阵营的朋友组队并且完成大部分事情**。
- 新版本主线剧情走向是一致的，但是可能有部分细节会有不同的分支侧写。
- 新版本的“主城”一般是通用的

### **阵营的差异点**  
- 拥有不同的种族
- 如果你打开PVP（玩家对战）开关，那么不同阵营玩家可以在野外相互攻击
- 跨阵营无法交易部分东西，需要组队进本才能交易
- 旧版本的绝大部分任务是区分阵营的，如果你想体验全部的旧剧情（非剧情偏好玩家完全没必要），单阵营乃至单种族角色是不够的
- 旧版本的“主城”是区分阵营的，它会影响你的一些游戏内交通（比如传送门，飞行点等）
- 部分物品外观、坐骑、称号、成就是区分阵营的（比如同类的战场成就头衔，部落为高阶督军，联盟为大元帅）
- 非组队的情况下，野外你可能看不到某些对立阵营玩家的喊话，比如一个联盟圣骑士说：“你好”，部落玩家可能看到的是“[人类语]：OIUTYOIS”
- 跨阵营无法正常排队某些需要地下城查找器的副本（比如时光漫游地下城）

### **部落的背景风格**  
- 部落由兽人、巨魔、牛头人、被遗忘者（亡灵）、血精灵等种族（下详）组成，崇尚力量、荣耀与坚韧，文化上更为原始狂野。代表主城是奥格瑞玛（兽人首都），其他还有幽暗城、雷霆崖、银月城。经典配色为红黑。

# 选择种族 ——喜欢>一切 

### 对新手的种族建议

>[!quote]如果你是第一次玩这个游戏，那么建议忽视掉所有的建议，**选择一个任何一个你喜欢的种族**。  

除顶级游戏内容（99%的玩家达不到这个场景）种族对于游戏的影响微乎其微。自己喜欢才是最重要的。  
种族对于新手更多的差异体现在外观、剧情线上，目前游戏内的每一个种族都拥有一条或者多条独特的剧情线（大部分是非强制的），以及一些种族的独特奖励。  

### 12.x“强力党”的选择
在12.x中，部分种族在满级内容中更受偏好，比如  
- 暗夜精灵，拥有影遁，可以在某些情况下规避战斗和脱离战斗
- 矮人，可以更好的应对当前版本频繁的“流血”负面状态
- 黑铁矮人（需同盟种族解锁），在应对负面状态的同时获得更多的收益
- 牛头人/至高岭牛头人，拥有更快的采集速度（生活技能），尤其是德鲁伊职业

### **种族特长**
![[Pasted image 20260929180657.png|356]]
魔兽世界的联盟和部落（阵营）分别可以选择不同的种族，你可以在建立角色的时候右键点击这些种族查看他们的天赋和背景介绍。

### **同盟种族解锁**
![[Pasted image 20260929180918.png|363]]  
除了联盟部落每个阵营各默认8个解锁种族外，每个阵营还**额外拥有7个同盟种族**。  
这些种族需要你至少拥有一个40级的角色，然后到阵营主城（联盟：暴风城 / 部落：奥格瑞玛）接取一系列简单的任务进行解锁。
- 哈籁尼尔除外，哈籁尼尔是最新版本推出的种族，所以需要在最新版本的主线任务第三章任务后解锁（这意味着至少80级）。  
解锁之后可以重新建立对应种族角色，或者对已有角色使用付费的“种族转换”服务即可使用。   
如果你想解锁某个种族，可以以该种族为关键字搜索解锁攻略。

# **选择职业和专精 ——喜欢>职责**

### **对新手的职业建议**
职业选择是一个极其个人化的事情，对于新手的建议依旧为**选择一个任何一个你喜欢的职业**。
如果你有一个看起来非常喜欢的职业，那么**请无视下方任何的建议**。

### **选择职业的思路**
**最简单的方法**  
找一个你看起来最顺眼的，找到自己喜欢的职业，**去体验、去玩，永远比看文字或者视频要强的多**

**如果你希望更严谨一些**  
- 先选择了解职责的大概意思（坦克/输出/治疗），以避免你在喜欢治疗其他玩家的情况下，错选了一个负责抗怪的职业。
- 大致了解职业和专精情况
- 根据自己的喜好找到对应的职业和专精（具体的概念参见下方）
	- 如果你喜欢抗住一切，带领队伍过关斩将，那么坦克显然是最优选择
	- 如果你喜欢和敌人近身肉搏，那么近战DPS
	- 如果你喜欢在远处进行施法带来成吨伤害，那么远程DPS
	- 如果你喜欢保护队友，那么选择治疗职业和专精
	- 如果你喜欢灵活切换，在不同职责之间中多修，那么多职责的混合职业肯定是最适合你的
- 如果你想，也可以在角色建立时，在右下方勾选“职业试玩”来体验较高等级的职业（但请注意，试玩角色并不是你真实的角色，如果你想将试玩角色转换为正式角色需要付费！），但我个人**不推荐**第一次玩的新手这么做。因为第一次玩就是要自己去体验、去踩坑、去从零到一从无到有的体验一个全新世界。
	![[Pasted image 20260929181047.png|576]]

而具体的职责、职业、专精对照表我放在下方

### **职责和战斗风格**
![[Pasted image 20260929181135.png|605]]  
在新手选择职业之前，可以想好自己**适合和喜欢什么职责和战斗风格**。  
你可以在**建立角色界面**选择职业时（如上图），查看该职业可以承担什么样的职责（对应不同专精）。  
魔兽世界的所有职业和专精都区分为3个职责，在**PVE**环境下
- **坦克**，俗称T、坦，负责拉住敌对目标、避免队友受到伤害。
- **伤害输出**，俗称DPS，负责对敌对目标造成伤害
- **治疗者**，俗称N、奶，负责治疗和保护队友
- 其他，当前只有一个特殊专精——“唤魔师”职业的“增辉”
	- 增辉是负责给队友释放增益和控制敌对目标的，本身并不直接产生伤害和治疗，所以更偏向“辅助”这一概念。而由于这些增益需要你对游戏和其他职业有一定了解，所以在此处并不额外过多介绍，也请新手不要看到“辅助”这两个字就认为是简单。  

不同职业可以通过不同专精来承担不同职责，所以当你选择一个职业，完全可以体验三种不同的游戏职责。
- 比如圣骑士职业拥有防护、惩戒、神圣3个专精
	- 防护：承担坦克（T）职责
	- 惩戒：承担输出（DPS）职责
	- 神圣：承担治疗（N）职责
- 请注意，不是每一个职业都可以承担不同职责，比如法师的3个专精（奥术、火焰、冰霜）都是负责输出的（DPS）  

所有的职责和专精各有所长，也各有所短，在游戏内需要相互配合才更合理。在魔兽世界典型场景下：
- 5人小队，一般为1个坦克+1治疗+3个DPS
- 20人团队，一般为2个坦克+4~5个治疗+若干DPS
	- 其中DPS在非特殊的情况下也是近战和远程搭配组队
所以，在此基础之上，你可以**根据自己的偏好和习惯来考虑职业选择**

### **职业和专精**
![image.png|635](https://cdn2.flowus.cn/oss/377fa335-4855-4afd-afc3-46cc5d45dda8/image.png?time=1790676000&token=f15cf1faf270b156b0cf398592050600e3c27090c727cd1d92ff52dd14dfc851&role=sharePaid)
魔兽世界当前有13个职业，目前所有职业都分为3个专精（德鲁伊较为特殊，为4个专精）。
- 专精：指的是当前职业可以选择不同分支，不同分支有不同的玩法，可以在游戏内**随时切换**。  

在刚进入游戏时并不会区分专精，而随着你到达**10级**或者完成一系列任务，则会解锁当前职业的专精分支（以及对应专精的天赋树）。  
你可以在游戏内按N或者在右下角系统条处随时找到“专精”和“天赋”页面，并且**查看职业专精的介绍**    
不同职业可以使用不同类型的武器和护甲  
- 武器类型，比如惩戒专精圣骑士是“伤害输出”职业，使用双手武器，虽然依旧可以使用单手武器和盾牌，但没有人会这么做
	- 同职业的防护专精，由于是“坦克”，则是单手武器+盾牌的职业
- 护甲类型，比如战士就是板甲职业，而法师则是布甲职业。
